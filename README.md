# Home Assistant Apps by chriss158

Chriss158's [Home Assistant Apps](https://www.home-assistant.io/apps/).

## Usage

1. Navigate in your Home Assistant frontend to __Settings -> Apps -> Install app__
2. Add this new repository by URL (`https://github.com/chriss158/home-assistant-addons`)
3. Find the app that you want to use and click it
4. Click on the "INSTALL" button

## Apps

* [Enhanced DuckDNS](enhanced-duckdns/)
* [Gotify] (gotify/)
* [DDNS-Updater] (ddns_updater/)
